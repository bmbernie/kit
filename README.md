# kit

`kit` is a collection of reproducible, small information-security hardware builds.

## Current Kits

- [`zerolab/`](zerolab/) — Raspberry Pi Zero W USB gadget platform with RNDIS, ACM serial, bounded HID keyboard support, optional read-only mass storage, Wi-Fi-to-Bluetooth PAN failover, PiSugar2 telemetry, and a Waveshare 2.13-inch V2 e-paper status display.
- [`pwnagotchi/`](pwnagotchi/) — Specifically configured for a Raspberry Pi 3B v1.2 with a serial-connected Holux GPS receiver, Waveshare 2.13-inch V2 e-paper display, and PiSugar 2 Pro. The build is based on Pwnagotchi (2.9.5.9 final-201303). It includes Bettercap startup and reliability fixes and corrects WiGLE API integration issues in the original tree.
