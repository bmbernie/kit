# kit

`kit` is a collection of reproducible, small information-security hardware builds.

## Current kits

- [`zerolab/`](zerolab/) — Raspberry Pi Zero W USB gadget platform with RNDIS, ACM serial, bounded HID keyboard support, optional read-only mass storage, Wi-Fi-to-Bluetooth PAN failover, PiSugar2 telemetry, and a Waveshare 2.13-inch V2 e-paper status display.
- [`pwnagotchi/`](pwnagotchi/) — specifically configured pi 3b v1.2, holux gps over serial unit, Waveshare 2.13-inch V2 e-paper eink display, and PiSugar 2Pro overlay derived from the accepted Pwnagotchi 2.9.5.9 `final-201303` build, including Bettercap startup hardening.  Fixed Wiggle integrations and API errors in original source.
